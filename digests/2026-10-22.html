Your stack

  • FastAPI: a burst of ten point releases this week, from 0.156.5 up to 0.159.1 — worth a `pip install -U fastapi` but check the changelog before upgrading past a minor bump.
  • Python 3.14: Python 3.15.1, 3.14.9 and 3.13.17 are out, routine bugfix releases across all three maintained lines.
  • Linters and type checkers: VS Code's Python extension now lets you swap in Pyrefly (or another type checker) alongside Pylance, useful if you've been eyeing ty or basedpyright as an alternative.
  • Security (AI and cloud): the week's big story is "PHP2Shell", a pair of critical PHP RCE flaws (CVE-2026-109618/109619) that triggered emergency patches, mass exploitation, and a CISA mandate to patch alongside Siemens and SiteGuard flaws; separately, LiteLLM's PyPI and Docker artifacts were compromised to deliver a credential stealer, AWS disclosed CVE-2026-112408 (a bucket-ownership gap in the SageMaker Python SDK's `default_bucket()`), a China-linked group hit ConnectWise via AI-agent tooling in a supply-chain attack, and AWS published best practices for IAM Roles Anywhere with your own PKI.
  • Terraform: HashiCorp's community is discussing a new Zoho Catalyst provider.
  • Azure DevOps / Checkmarx: Copilot's Autofix for GitHub Advanced Security moved to an agentic foundation and now also fixes dependency vulnerabilities and code-scanning alerts raised by third-party SAST tools.
  • WSL: PowerToys 0.102 ships new mouse utilities and Command Palette improvements.
  • MCP: Amazon WorkSpaces now authenticates AI agents via MCP directly, removing the need to hand-roll streaming-URL rotation for agent desktop sessions.
  • EventBridge: CloudWatch alarms now carry their tags into the EventBridge events they emit, so you can route/filter on tags without an extra lookup.
  • boto3: routine point release, now at 1.43.117.
  • Claude: Anthropic shipped API version 2026-10-21 with major version bumps across every client SDK (Python to 2.0.0/2.1.0, TypeScript 1.0.0, Go 2.0.0, Java 3.0.0 and more) — worth checking for breaking changes before you upgrade; Strands Agents hit 1.62.0, and AWS published a Strands + Bedrock pattern for routing routine work to local small models and complex requests to the cloud; separately, Latent Space's "Claude Mods" piece is worth a read if you're thinking about agent-harness design.
  • Claude Code: 2.1.307 adds a flag to pin API version 2026-10-21 and a new `claude_code.safety_event` OpenTelemetry event for permission/sandbox/hook interventions, and 2.1.308 is a bugfix follow-up; the Python Agent SDK moved to 0.2.172; and Simon Willison's sparqlite experiment is a good demo of Claude Code's "Ultracode" dynamic-workflow mode in practice.
  • Step Functions / Amazon Bedrock: AWS's architecture blog walks through automating medical coding with Step Functions and Bedrock AgentCore.
