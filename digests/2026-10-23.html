Separately, CLI 2.1.309 fixes a VS Code certificate-verification warning and tweaks the bundled dataviz skill's contrast handling, and the Claude Agent SDK ticked to 0.2.173.

  • Amazon Bedrock: AgentCore Gateway now proxies InvokeModel/InvokeModelWithResponseStream with automatic model-fallback routing, so one governed endpoint can fail over across providers. A case study shows IskayPet running a multilingual knowledge assistant on Bedrock Managed Knowledge Bases with no RAG infrastructure of its own.
  • AI-DLC and AI-assisted development: AWS published a case study of Rescale using the AI-DLC framework with Strands Agents and Bedrock to build a test-triage agent in weeks. GitHub Copilot in Visual Studio's September update adds in-chat PR review and auto-fixes for flagged vulnerable packages, and Copilot features are now on by default for eligible orgs.
  • Dependabot and supply chain: Snyk's Evo Remediation Agent entered open preview, turning a dependency-vulnerability backlog into ready-to-merge pull requests automatically.
  • GitHub Actions: a minor Meta API change for how Actions blob storage is addressed — only matters if you call that endpoint directly.
  • GitHub Enterprise: Public monitoring for GHEC with data residency is in public preview, extending secret scanning beyond internal repos.
  • MCP: the Agentic AI Foundation welcomed Open Responses as a project alongside MCP and A2A. Separately, a flaw in OpenCode let a malicious MCP server execute code at sign-in on Windows and WSL (patched in 1.18.33) — a reminder to vet MCP servers before connecting.
  • Terraform: CVE-2026-115414 is an OS command-injection bug in AWS SAM CLI's Terraform hook (sam build --hook-name terraform), from unsanitized shell metacharacters in a resource address — update SAM CLI if you use it.
  • Entra ID: Wiz is tracking an ARTEX-using actor (overlapping with Storm-0940) that targets Okta, Entra ID, and Cognito tenants at IT and software vendors.
  • Security (AI and cloud): AWS Continuum for code vulnerabilities went GA, auto-triaging findings and opening PR fixes. tl;dr sec flags a new tool that automates exploiting AWS IAM privilege-escalation paths. Real Python has a primer on supply-chain security lessons from the LiteLLM backdoor. And Railway disclosed a possible breach exposing customer environment variables, urging credential rotation.
