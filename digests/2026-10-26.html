The Claude Agent SDK (Python) ticked to 0.2.174.
  • AI-DLC and AI-assisted development practices: AWS's open-source team introduced Infinity, a runtime built for coding agents that spend most of their time blocked on a long build or waiting hours for the next pull request.
  • Security (AI and cloud): AWS disclosed CVE-2026-111943 — a key-generation flaw let eMudhra/emSign intermediate CA private keys be recovered, exposing soft-fail TLS clients, including ALB OIDC/JWT auth, to man-in-the-middle risk, so AWS is pulling the roots from its trust bundles. A Brotli decoder memory-corruption flaw (CVE-2026-111497) reaches past Node.js into the Python brotli and brotlicffi packages and Bun. A critical Pillow flaw (CVE-2026-112900) lets a crafted EPS image run arbitrary OS commands via its Ghostscript handoff. And the Real Python podcast talks supply-chain defense with the PSF's security developer-in-residence, Seth Larson.
