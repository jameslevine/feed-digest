Your stack

  • uv: tar-codec, Astral's new Rust tar encoder/decoder, is now uv's default and more than doubles its tar-handling speed while hardening against archive differentials.
  • Linters and type checkers: Real Python published a walkthrough of Pyrefly, Meta's fast Rust-based type checker, covering catching type errors, generating annotations and measuring coverage; separately, ty 0.0.93 is a routine patch release of Astral's type checker.
  • pytest: pytest 9.2.0 is out.
  • boto3: boto3 1.43.120 ships the usual batch of updated AWS service models.
  • Amazon Bedrock: AWS shows how to build document-investigation agents where an AWS Lambda function and a Bedrock AgentCore agent share an Amazon S3 Files file system using ordinary file operations instead of upload/download code; separately, a Bedrock customer writeup on fixing evaluation bias found 96.8% of their vision-AI eval labels were inherited from the incumbent model, masking its true accuracy — worth a look if you lean on model evals.
  • Azure DevOps: the Azure DevOps Server RC (26H2) is available, bringing previously hosted-only features plus security and quality fixes on-prem.
  • MCP: Real Python's MCP vs. API calls piece builds one Python tool both ways and compares what each approach costs and when an MCP server actually pays for itself.
  • Claude Code: 2.1.312 adds an effort-level picker for cloud routines, an oidc.user_id_claim option so the apps gateway can identify people by a claim other than sub (handy for Microsoft Entra ID's oid), and fixes subagent/prompt hooks running more than their intended 24-at-a-time limit.
  • AI-DLC and AI-assisted development practices: Real Python's overview of AI coding agent workflows breaks them into IDE, terminal, PR and cloud types and how each fits modern Python development; GitHub Copilot now supports server-to-server authentication for GitHub Apps on organizations (public preview), letting Copilot SDK-built services and agents make requests without a human in the loop; and AWS walks through using Kiro to build a SCORM pipeline that converts raw training material into LMS-ready packages.
  • Security (AI and cloud): Apple backported a fix for CVE-2026-86950, an actively-exploited CoreGraphics out-of-bounds write (CVSS 8.8), to older iPhones and iPads; Microsoft fixed CVE-2026-80097 in Authenticator for Android, where a permissionless malicious app could impersonate a trusted app like Teams and steal work-account sign-in tokens; and Node.js v24.22.1 and v22.23.4 are security releases fixing ten CVEs, including a Brotli-decoder flaw ("node2shell") that can lead to remote code execution.
