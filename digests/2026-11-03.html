Your stack

  • Python 3.14: Real Python's November roundup notes that Python 3.15 has shipped, 3.16 is eyeing None-aware operators, and eight broken CA keys triggered emergency security releases.
  • uv: uv 0.13.7 is out (no changelog beyond the version bump on PyPI).
  • Linters and type checkers: ty 0.0.96 shipped, Astral's Rust-based Python type checker.
  • GitHub Actions: GitHub will block pull_request_target by default in all public repos from December 2, unless an Actions event policy explicitly allows it — worth auditing any public-repo workflows that rely on it.
  • AWS Lambda: Lambda event source mappings now support queue consumption mode for self-managed Apache Kafka (including Confluent Cloud), scaling consumer parallelism past partition count with per-record acks and automatic retries.
  • EventBridge: A new AWS Architecture Blog post shows a Lambda-free pattern for automating the full AWS DRS agent lifecycle (install/heal/offboard) with EventBridge-triggered Systems Manager Automation.
  • MCP: Amazon Connect flows can now call MCP tools directly via Bedrock AgentCore Gateway, and AWS's own internal DevOps Agent gained MCP server support, Skills, and custom connectors — more signs MCP is becoming AWS's default tool-calling layer.
  • Amazon Bedrock: Three separate posts on Bedrock AgentCore patterns this week: Crawl4AI for Knowledge Bases content prep, an AgentCore + Nova-embeddings pattern built on the Strands Agents SDK, and a Circle K case study cutting DevOps incident triage to under 15 minutes.
  • Step Functions: This week's AWS Weekly Roundup highlights Step Functions now being callable as an agent tool, so existing orchestrations (it already coordinates 220+ AWS services) become agent-usable without a rewrite.
  • Claude: Claude Haiku 5.5 is now available in Kiro for AWS GovCloud (US), completing the Claude 5.5 family there; the Claude Platform API picked up beta "message threads" for cheaper, lower-latency long agent conversations; and the Anthropic Python SDK bumped to 2.4.0.
  • Claude Code: 2.1.317 adds a warning when a new cloud scheduled task gets connectors you didn't ask for, a confirmation before a web/shell tool call sends your account email over the network, and onFailure: "block" for Agent SDK hook callbacks; the Claude Agent SDK also bumped to 0.2.177.
  • AI-DLC and AI-assisted development practices: CVE-2026-120497 — a stored XSS in aidlc-traceability, the tool that builds traceability-matrix reports from AI-DLC artifact files; patch if you use it.
  • Microsoft Teams: Attackers are impersonating IT support on Microsoft Teams to get remote control of PCs, then abusing weak AD CS settings to mint certificates for privileged accounts, including a domain controller — worth reminding staff that Teams-based IT requests need verification.
  • Security (AI and cloud): CVE-2026-116635 is a path-traversal bug in the AWS Serverless MCP Server's deployment-status component. Separately, critical unauthenticated-RCE flaws hit Langflow, the open-source AI agent/workflow builder.
