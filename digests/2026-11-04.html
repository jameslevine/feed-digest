Your stack

  • Python 3.14: PyCoder's Weekly covers PEP 836's withdrawal, removing the experimental JIT from CPython's main branch; separately, CodeQL 2.27.3 adds Python 3.15 language support and Dependabot now supports upgrading to Python 3.15.
  • Powertools for AWS Lambda: 3.39.0 shipped (no changelog beyond the version bump).
  • AWS Lambda: Lambda now supports Seekable OCI (SOCI) lazy loading for Managed Instances, cutting container startup time up to 70% by fetching only the files each stage needs.
  • Step Functions: Step Functions workflows are now usable as AI agent tools through Bedrock AgentCore Gateway — your agent decides when to invoke an existing Standard/Express workflow.
  • DynamoDB: DynamoDB Accelerator (DAX) is now available in Canada (Central) and Africa (Cape Town).
  • Amazon Bedrock: AgentCore CLI 1.0 is GA with faster startup and a consistent command structure; a new post shows AgentCore Gateway doing on-behalf-of token exchange with Entra ID for ServiceNow calls with no interceptor Lambda; and Bedrock added India in-country inference for Kimi K3.
  • Claude Code: a trojanized Claude Code extension (v2.1.313) was distributed via the Cursor Marketplace under the real publisher identity, installing a persistent SSH backdoor — check what version you're running; separately, 2.1.318 added an `assume_role` option for per-developer AWS cost attribution and an effort override for forked subagents.
  • Claude: the Nov 3 platform release notes detail which models carry the text watermark (and when a non-default temperature/top_p/top_k suppresses it on Sonnet 4.6); claude-agent-sdk 0.2.178 also shipped.
  • Dependabot and supply chain: Dependabot version updates now cover Agent Package Manager (APM), so it can open PRs to keep your AI agent skills, prompts and instructions current too.
  • MCP: CVE-2026-115413 is an OAuth token audience-validation bypass in the AWS API MCP Server — worth checking if you're running it.
  • AI-DLC and AI-assisted development practices: GitHub Copilot usage API now reports BYOK vs. Copilot-hosted model usage separately, Copilot is now available in JetBrains Air via the Agent Client Protocol, and an AWS post walks through building an org-wide RDS deletion-protection posture dashboard with Kiro.
  • Security (AI and cloud): HashiCorp/IBM launched a managed Vault Enterprise on dedicated IBM Cloud infrastructure; Google warned that LLMjacking (hijacked LLM API access) is costing some enterprises up to $1M in cloud charges; Binance traced its record $6.43B theft to a tampered Homebrew install and AI-tool-abetted social engineering against two engineers; and Wiz surveys the rise of agentic attacks and their fingerprints.
