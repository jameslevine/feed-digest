Security

  • A MitM flaw in APT lets an attacker swap a verified Debian/Ubuntu package for their own and run code as root, by abusing APT's default retry-on-failure behavior.
  • A critical Rails/Active Storage flaw lets an unauthenticated attacker write arbitrary server files via a crafted ImageMagick upload; fixed in 8.1.4.1/8.0.5.2.
  • Two Xen hypervisor flaws let a malicious guest VM read and write other VMs' memory, including dom0; no mitigation beyond patching.
  • OpenAI's cyber-focused AI pipeline found and patched 948 Linux local-privilege-escalation bugs for $1.2M in API costs.
  • Google warns LLMjacking (hijacked LLM API access) is costing some enterprises up to $1M in cloud charges.
  • Most AI agents never pass through a gateway the enterprise controls, so runtime-security promises that assume one don't hold — illustrated by a real mass-email automation incident.
