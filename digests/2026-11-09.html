Your stack

  • Python 3.14: Real Python dug into how CPython manages memory (arenas, pools, blocks) and its podcast covered free-threaded Python and the CPython ABI — useful background while free-threading keeps rolling out.
  • Linters and type checkers: Astral shipped ty 0.0.99, another point release of the Rust-based type checker.
  • FastAPI: FastAPI 0.162.2 shipped (and 0.162.1 just before it).
  • boto3: boto3 1.43.126 shipped.
  • Amazon Bedrock: Kimi K3.1 Pro (Highspeed) landed on Bedrock as a new open-weight model option. AWS also posted a two-part guide to governing AI agent access with Okta Cross App Access and AgentCore (part 2), binding agent identity to end users via Cedar policies — relevant if you're building agent authn/authz. Case studies from Greenlight Financial's autonomous SOC and Taxbit Assist show AgentCore in production, and AWS Agent Registry went GA in GovCloud (US-West).
  • GitHub Actions: Platform Engineering's "Beyond SHA pinning" argues pinned SHAs don't guarantee provenance and walks through how imposter commits exploit CI/CD workflows — worth a read for your supply-chain posture.
  • Checkmarx: Checkmarx joined the Claude Marketplace, letting Anthropic customers put spend toward Checkmarx Fusion SAST, Triage and Remediation Assist.
  • MCP: Spring AI 2.1.0-RC2 adds server support for the new MCP protocol revision. Microsoft's Work IQ API is getting SharePoint MCP tools for custom apps and agents, and AWS posted a walkthrough of a serverless MCP server on ECS Fargate for data-lake access.
  • Claude: researchers showed malicious browser extensions could abuse Claude Dispatch to run code on a user's computer via claude.ai — worth knowing if you run Claude Desktop with browser extensions installed.
  • Claude Code: two security stories worth your attention: Claude Code's "Don't Ask Again" file is exposing passwords and keys in 1,122 public GitHub repos (check your own repos for a committed settings file), and a fake Claude Code extension that tried to open a backdoor. On the feature side, 2.1.319 adds background MCP task support in the terminal, claude-agent-sdk 0.2.179 shipped, and AWS published a guide to running Claude Code as a remote AgentCore session with per-task isolation.
  • AI-DLC and AI-assisted development practices: GitHub Copilot got a flurry of updates — code review settings via API, and JetBrains Air/Xcode support plus an Agent Merge mode — alongside a GitHub blog post on what agentic engineering still needs human judgment for. Simon Willison suggests hiding noisy agent-generated PR descriptions behind <details><summary> if you're shipping a lot of Claude Code or Codex PRs. Elsewhere, Stanford's AI-native engineering course brought open-source maintainers in to grade student work, and Daniel Miessler argues real vibe coding isn't just "using AI to make things."
  • Security (AI and cloud): InfoQ on identity as an architectural concern argues IAM design choices drive your data models and service boundaries, not just authentication.
