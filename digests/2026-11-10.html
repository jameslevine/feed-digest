Your stack

  • Linters and type checkers: Astral shipped ty 0.0.100, another point release of its Rust-based Python type checker.
  • boto3: boto3 1.43.127 shipped.
  • DynamoDB: This week's AWS Weekly Roundup highlights AgentCore Runtime V2 and new DynamoDB bulk put items support for writing large batches more efficiently.
  • Amazon Bedrock: AgentCore's Web Search API went GA, giving agents single-call web search without standing up your own MCP tool. AWS also posted a memory-poisoning defense pattern using multi-layer write validation for AgentCore Memory, a seven-layer reference architecture for taking agentic AI to production on AgentCore, and case studies on CrossnoKaye grounding physical AI in live plant data and Novus Hi-Tech's FleetGPT cutting road-behavior violations 46%. Bedrock Managed Knowledge Base also picked up single-shot, retrieval-only requests alongside agentic retrieval.
  • GitHub Actions: GitHub's secret scanning now covers Actions workflow logs (public preview), alongside issues, wikis, discussions and PRs.
  • MCP: Snyk's guide to governing AI coding agents' MCP servers covers inventorying MCP servers, assessing risk and blocking high-risk connections without disrupting developers.
  • Claude: Anthropic launched Claude Fable 5.2 and Claude Mythos 5.2, both 1M-context, always-on-thinking models (Mythos is restricted to verification-program customers). Fable 5.2 is now the default model in Claude Code 2.1.321 ($8/$40 per Mtok, $0.20/Mtok cache reads) and shipped on AWS and AWS GovCloud, with fast-mode pricing ($16/$80 per Mtok) landing in the Messages API and, per Claude Code 2.1.322, on Vertex. GitHub Copilot also added Fable 5.2. Simon Willison dug into how Fable 5.2 reads prompts about code ownership and added it to llm-anthropic 0.31; anthropic 2.7.0 and claude-agent-sdk 0.2.180 shipped alongside the launch.
  • Security (AI and cloud): AWS flagged two CVEs in the Braket SDK (hybrid-job input download, error-mitigation schema validation) and a path-traversal CVE in ParallelCluster CLI's log-export commands. Datadog's ARTEX writeup shows an AI-native pentesting framework hunting CloudWatch logs and abusing public Cognito pools in the wild, and Wiz traced a breach back to abused IAM credentials from Qubole's own AWS integration.
